# ☕ Café, Teria? — Landing Page

O Café, Teria? é uma landing page moderna e responsiva desenvolvida para uma cafeteria fictícia. O projeto foi estruturado para apresentar o conceito do espaço, a história da marca e um cardápio interativo, focado em uma experiência de usuário visualmente atraente e fluida.

## 🚀 Tecnologias Utilizadas

O projeto foi construído do zero utilizando as tecnologias fundamentais da web:

- HTML5: Estruturação semântica de todo o conteúdo e seções da página.
- CSS3: Estilização personalizada, paleta de cores harmoniosa, tipografia e layout responsivo.
- JavaScript (ES6): Implementação de interatividade e dinamismo na navegação.

## ✨ Funcionalidades

- Design Responsivo: Adaptado perfeitamente para visualização em desktops, tablets e dispositivos móveis.
- Navegação Inteligente: Links de ancoragem no menu superior para rolagem suave até as seções específicas (Início, Sobre, Cardápio).
- Galeria Expositiva: Seção visual destacando a ambientação e a experiência interna da cafeteria.
- Cardápio Digital: Exibição organizada de produtos com preços, imagens e descrições detalhadas.

## 🛠️ Como Executar o Projeto

Para visualizar o projeto localmente em sua máquina, siga os passos abaixo:

1. Clone este repositório:

```bash
git clone https://github.com/Fabibourdokan/CafeTeria.git
```

2. Navegue até a pasta do projeto:

```bash
cd CafeTeria
```

3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server no VS Code.
